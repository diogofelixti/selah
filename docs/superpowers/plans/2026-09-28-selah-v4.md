## Review Focus

1. Trecho que não cabe nem em 36 px desativa a opção, sem gerar imagem cortada.
2. Palavra maior que a largura (sem espaço para quebrar) não trava o laço de quebra de linhas.
3. Cancelar o compartilhamento não mostra erro.
4. A fonte Lora já está carregada quando a imagem é desenhada.

### Task 1: Layout da imagem

**Files:** Create `src/lib/verse-image.ts`, `src/lib/verse-image.test.ts`

**Interfaces:**
- `type Measure = (text: string, fontSize: number) => number` (largura em px)
- `layoutVerseImage(text: string, measure: Measure, opts?: { width?: number; maxHeight?: number; maxSize?: number; minSize?: number; lineHeight?: number }): { fontSize: number; lines: string[] } | null` (null quando não cabe)
- `imageFilename(book: string, chapter: number, verses: number[], bookName: (id: string) => string): string` (sem acentos, minúsculas, hífens: `selah-joao-3-16.png`, `selah-joao-3-16-18.png`)

**Casos:** quebra por palavras sem passar da largura; texto curto usa o tamanho máximo; texto maior diminui até caber; nada cabe em 36 px devolve null; palavra única mais larga que a linha fica sozinha numa linha sem travar; nome do arquivo com acento e intervalo.

- [ ] Teste falhando, implementação, teste passando, commit `feat: layout da imagem de versículo`.
