# Selah v2.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar a tipografia pela opção A (Lora e Source Sans 3) e permitir selecionar, copiar e compartilhar versículos.

**Architecture:** A fonte muda só nos pacotes Fontsource e nos três tokens de fonte. A cópia é uma função pura que monta o texto (`formatSelection`), um utilitário de área de transferência com fallback (`copyText`) e, no leitor, um estado de seleção com barra de ações. Home e Temas ganham um botão de copiar ao lado do link, e não dentro dele, para não aninhar elementos interativos.

**Tech Stack:** o mesmo da v2. Sai Fraunces, Manrope e Literata; entram `@fontsource-variable/lora` e `@fontsource-variable/source-sans-3`.

**Spec:** `docs/superpowers/specs/2026-09-28-selah-v2-1-fonte-e-copia.md`

## Global Constraints

- Regras da v1 e da v2 continuam: sem travessão nem meia risca (hífen comum é permitido), pt/en com as mesmas chaves, alvos de 44px, contraste AA, só tokens de cor.
- Fontes: `--font-display` e `--font-read` = Lora; `--font-ui` = Source Sans 3. Tudo via Fontsource.
- O texto bíblico copiado não muda palavras. As palavras implícitas saem sem colchetes, e a sigla da tradução vai sempre no fim.
- Trabalhar no branch `feat/mvp`. Commits em português, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Ao fim do plano, passam `npm run check`, `npm test` e `npm run e2e`.

## Review Focus

1. **Seleção fora de ordem** (tocar 18, depois 16, depois 17): o texto sai em ordem e a referência vira `16-18`. Teste unitário na Task 2.
2. **Versículos vazios da BSB** (ex.: Mateus 17:21 não existe no leitor): não entram na cópia e não viram intervalo falso. Teste unitário na Task 2.
3. **Cópia sem HTTPS** (rede local): o fallback funciona e mostra "Copiado". Teste de componente na Task 2 e e2e na Task 3.
4. **Trocar de capítulo com versículos selecionados:** a seleção é limpa e não carrega números do capítulo anterior. Teste e2e na Task 3.
5. **Toque num versículo não pode quebrar o que já existe:** destaque do versículo aberto por link, marcar como lido e navegação continuam funcionando. Os e2e existentes do leitor na Task 3.

`src/lib/bible/copy.ts`:

```ts
function stripBrackets(text: string): string {
  return text.replace(/\[([^\]]+)\]/g, '$1')
}

/** "1-3, 5". Hífen comum: a regra do app proíbe travessão e meia risca, não hífen. */
function ranges(verses: number[]): string {
  const parts: string[] = []
  let start = verses[0]
  let prev = verses[0]
  for (const v of [...verses.slice(1), Number.NaN]) {
    if (v === prev + 1) {
      prev = v
      continue
    }
    parts.push(start === prev ? `${start}` : `${start}-${prev}`)
    start = v
    prev = v
  }
  return parts.join(', ')
}

export function formatSelection(opts: {
  book: string
  chapter: number
  verses: readonly number[]
  texts: readonly string[]
  bookName: (id: string) => string
  translation: string
}): string {
  const verses = [...new Set(opts.verses)].filter((v) => opts.texts[v - 1]).sort((a, b) => a - b)
  if (verses.length === 0) return ''
  const ref = `${opts.bookName(opts.book)} ${opts.chapter}:${ranges(verses)} (${opts.translation})`
  if (verses.length === 1) return `“${stripBrackets(opts.texts[verses[0] - 1])}” ${ref}`
  const body = verses.map((v) => `${v} ${stripBrackets(opts.texts[v - 1])}`).join(' ')
  return `${body} ${ref}`
}
```

`src/lib/clipboard.ts`:

```ts
function legacyCopy(text: string): boolean {
  const area = document.createElement('textarea')
  area.value = text
  area.setAttribute('readonly', '')
  area.style.position = 'fixed'
  area.style.opacity = '0'
  document.body.appendChild(area)
  area.select()
  try {
    return document.execCommand('copy')
  } catch {
    return false
  } finally {
    area.remove()
  }
}

/** Copia texto. Sem HTTPS o navegador não oferece navigator.clipboard, então cai no método antigo. */
export async function copyText(text: string): Promise<boolean> {
  if (navigator.clipboard?.writeText) {
    try {
      await navigator.clipboard.writeText(text)
      return true
    } catch {
      // Permissão negada: tenta o método antigo.
    }
  }
  return legacyCopy(text)
}
```
