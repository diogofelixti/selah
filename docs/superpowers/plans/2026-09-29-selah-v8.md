# Selah v8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API com Postgres para o frodo e lembrete diário por Web Push.

**Spec:** `docs/superpowers/specs/2026-09-29-selah-v8-servidor-e-lembrete.md`

**Execução:** nativa, pelo autor. Cada tarefa começa pelo teste que falha.

## Global Constraints

- Os mesmos das versões anteriores: sem travessão, pt/en paritários, alvos de 44px, só tokens de cor, commits em português com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Segredos só em `.env` (fora do git).
- Nada é publicado no frodo sem o dono pedir.

## Review Focus

1. O `endpoint` de push não permite chamar endereços arbitrários (SSRF).
2. O agendador não envia duas vezes no mesmo dia, nem para quem já leu. Ele sobrevive a reinícios.
3. O novo service worker mantém o offline e o aviso de atualização (sem trocar de versão sozinho).
4. As mensagens de erro do lembrete deixam claro o que fazer (iPhone, permissão, sem rede).
5. Backup antigo (sem `reminder`) continua importando.
