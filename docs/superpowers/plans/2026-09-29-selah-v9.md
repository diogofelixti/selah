# Selah v9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Login com Google e sincronização de leituras, planos, destaques e notas entre aparelhos.

**Spec:** `docs/superpowers/specs/2026-09-29-selah-v9-conta-e-sincronizacao.md`

**Execução:** nativa, pelo autor. Cada tarefa começa pelo teste que falha.

## Global Constraints

- Os mesmos das versões anteriores: sem travessão, pt/en paritários, alvos de 44px, só tokens de cor, commits em português com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Segredos só no `.env`.
- Nada é publicado no frodo sem o dono pedir.
- O verificador de teste do Google só existe fora de produção.

## Review Focus

1. Nenhum dado some na junção: dois aparelhos offline que marcam e desmarcam coisas diferentes convergem para o mesmo resultado.
2. Token de sessão e token do Google: verificação completa (audiência, emissor, expiração, e-mail verificado); o servidor guarda só o hash.
3. O que muda no aparelho durante uma sincronização não é perdido nem desfeito.
4. Apagar dados com conta não traz os dados de volta; excluir conta apaga tudo no servidor.
5. Sem client ID, sem rede ou com o servidor fora do ar, o app segue normal (só a área de conta avisa).
